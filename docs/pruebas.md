# Estrategia de pruebas

## Backend (Fase 9)

- Tests unitarios de reglas de dominio: transiciones de estado, cancelación, FFD.
- Tests de servicios con dependencias mockeadas.
- E2E mínimos para endpoints críticos si aportan valor.

## Frontend

- Verificación manual de flujos principales.
- Tests de componentes solo en piezas críticas si hay tiempo.

## Criterio

Cubrir reglas de negocio relevantes. No se persigue cobertura total.
